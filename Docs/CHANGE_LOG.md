# CHANGE_LOG

이 프로젝트를 만들면서 내린 판단들을 시스템, 메커니즘, 아트로 나눠 적습니다. 설계 전체는 [[Stack_기획서]]에 있습니다.

## 시스템

- **코드 구조를 직접 파악할 수 있는 규모로 만든다.**
	- 1시간 안에 끝낼 수 있는 분량으로 잡고, 클래스마다 책임을 하나씩 갖게 나눴습니다.
- **기획서는 파일 하나, Obsidian으로 관리한다.** `
	- Docs/` 아래에 md 파일로 두고, 흐름도는 mermaid 문법으로 썼습니다.
- **구현 순서를 체크리스트로 만들어 하나씩 진행한다.**
	- 한 항목을 끝내고 확인한 뒤 다음으로 넘어갑니다.
- **3D 큐브와 직교 카메라를 쓴다.** 
	- 원작 분위기를 내기 위해 쿼터뷰(yaw 45° / pitch 35°)로 고정했습니다.
- **최고점은 PlayerPrefs에 저장한다.** 
	- 서버 없이 로컬에 저장하는 정도로만 둡니다.
- **UI 텍스트는 TextMeshPro를 쓴다.** 
	- TMP 필수 리소스는 직접 설치했습니다.
- **판정 수식을 별도 클래스로 분리하지 않고 `StackController.Place()`에 통합했다.** 
	- Unity API(`Mathf`)를 바로 쓰는 쪽이 이 규모에서는 더 단순하다고 판단했습니다.
- **SOLID/OOP 점검 후 두 가지만 고쳤다.**
	- 배경을 `BackgroundController`로 분리했고, 블록의 색·바운스·낙하를 `Block` 컴포넌트로 옮겼습니다. 클래스 개수가 늘어나는 것은 문제로 보지 않았습니다.
	- 인터페이스 추상화는 구현체가 하나뿐이라 하지 않았습니다.
- **저장소는 공개로 만들고 description에는 게임의 핵심 규칙을 요약해 썼다.**
- **웹 빌드는 별도 브랜치(`gh-pages`)에 올려 GitHub Pages로 서비스하고, README에 링크를 건다.**
	- 에디터 플레이와 차이가 없을 때만 올리기로 했습니다.
- **웹 빌드는 HDR을 끄고 Gzip + Decompression Fallback으로 압축한다.**
	- 이전 프로젝트에서 HDR이 켜져 있으면 3D가 보이지 않던 오류를 참고했습니다.

## 메커니즘

- **Stack 장르의 핵심 규칙을 그대로 따른다.**
	- 블록이 좌우로 왕복하고, 탭하면 멈춰 쌓이고, 어긋난 부분은 잘려 나가며, 전혀 겹치지 않으면 게임 오버입니다.
- **조작감을 가장 중요하게 본다.**
	- 입력은 즉시 반응하되 약간의 snap을 줘서 플레이어가 "내가 잘한다"고 느끼게 합니다.
	- 탭한 프레임에 바로 판정합니다.
	- 허용 오차(0.1) 안이면 Perfect로 보고 위치를 보정하며 자르지 않습니다.
- **블록은 등속으로 움직인다.** 
	- 속도가 읽혀야 맞췄다는 확신이 생긴다고 봤습니다.
- **점수는 쌓은 층수, 콤보는 연속 Perfect 횟수로 따로 센다.** 
	- 콤보 UI는 2부터 표시합니다.
- **X축과 Z축을 번갈아 등장시키는 것은 유지하고, 각 축에서 -에서 +로 갈지 +에서 -로 갈지는 블록마다 무작위로 한다.** 
	- 처음에는 항상 같은 방향이라 단조로웠습니다.
- **연속 Perfect일 때 블록 폭을 조금씩 회복시키는 보상을 넣기로 합의했다.** 
	- 아직 구현하지 않았습니다.
- **착지 바운스, Perfect 링, 콤보에 따라 올라가는 음높이를 넣는다.** 
	- 탭했다는 확인과 무게감을 주는 피드백입니다.
- **짧은 hit-stop을 넣는다.** 
	- Perfect일 때 0.04초 멈춥니다.
- **게임 오버 시 줌아웃해서 플레이어가 쌓은 결과물을 보여 준다.** 
	- 탑이 화면 가운데에 오고, 점수 패널은 위아래로 비켜 서게 했습니다.

## 아트

- **리소스를 쓰지 않고 원작 같은 분위기를 낸다.** 
	- 이미지·사운드 에셋 없이 그라데이션, 별, 효과음을 모두 코드로 만들었습니다.
- **그레이스케일은 기본값으로만 두고, 층별 색조 변화를 허용한다.** 
	- 층마다 HSV 색조를 조금씩 옮기는 파스텔 톤입니다.
- **스카이박스와 조명도 파스텔로 맞춘다.**
- **배경은 참고 이미지(라벤더에서 핑크, 크림으로 이어지는 그라데이션과 반짝이는 별) 느낌으로 바꿨다.** 
	- 층이 오르면 그라데이션 색조도 블록 색조를 따라 천천히 옮겨 갑니다. 
	- 톤매핑 때문에 색이 탁해져서 카메라 포스트 프로세싱은 껐습니다.
- **게임 오버 화면은 탑이 가려지지 않게 배치한다.** 
	- 패널 배경은 거의 투명하게 하고, 점수는 위쪽, Restart 버튼은 아래쪽에 둡니다.
